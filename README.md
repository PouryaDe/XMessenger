# 🛡️ XMessenger (ایکس مسنجر)

> **پیام‌رسان متمرکز و یک‌طرفه (Hub-and-Spoke Secure Web Messenger)**
> طراحی شده برای امنیت حداکثری، دوزبانه (فارسی راست‌چین و انگلیسی)، پیام‌های گذرا (حذف خودکار پس از انقضا)، حذف آنی دوطرفه و استقرار خودکار یک‌خطی لینوکس با گواهی SSL رایگان.

---

## 🌟 ویژگی‌های کلیدی

- **مدل ارتباطی یک‌طرفه (Hub-and-Spoke):**
  - ارتباط انحصاری کاربر با ادمین؛ کاربران به هیچ وجه نمی‌توانند یکدیگر را ببینند یا به هم پیام ارسال کنند.
  - ادمین به صورت متمرکز تمام گفتگوها را مشاهده، مدیریت و پاسخ می‌دهد.
- **رابط کاربری واکنش‌گرا و مدرن (PWA Mobile & Desktop):**
  - ظاهر الهام‌گرفته از تلگرام/سیگنال برای موبایل و دسکتاپ.
  - پشتیبانی کامل از زبان‌های فارسی (RTL با فونت بهینه وزیرمتن) و انگلیسی (LTR).
  - پشتیبانی از تم تاریک و روشن (Dark / Light mode).
- **پیام‌های گذرا و امنیت حداکثری (Ephemeral & Auto-Destruct):**
  - حذف خودکار پیام‌ها به صورت دوطرفه پس از انقضا (پیش‌فرض ۲۴ ساعت، قابل تغییر در تنظیمات ادمین از ۱۵ دقیقه تا چند روز).
  - حذف قطعی آنی (Delete for Everyone) در هر لحظه توسط کاربر یا ادمین.
  - پاکسازی سخت‌افزاری (Hard-delete) از دیتابیس توسط جاب پس‌زمینه TTL.
- **امنیت و رمزنگاری داده‌ها:**
  - رمزنگاری اطلاعات حساس و متن پیام‌ها در سطح دیتابیس با استاندارد **AES-256-GCM**.
  - هش امن رمزهای عبور با الگوریتم مقاوم **bcrypt** با Salt بالا.
  - توکن‌های امنیتی JWT و ارتباطات بلادرنگ بر بستر Secure WebSocket (WSS).
- **کنترل ثبت‌نام در پنل ادمین:**
  - کلید فعال‌سازی/مسدودسازی ثبت‌نام عمومی.
  - حالت تایید دستی (Manual Admin Approval): کاربران جدید در وضعیت «در انتظار تایید» قرار می‌گیرند تا پس از تایید توسط ادمین دسترسی چت فعال شود.
- **اسکریپت نصب یک‌خطی لینوکس:**
  - استقرار با یک دستور بر روی سرورهای ابری (Ubuntu/Debian) با Nginx و گواهی رایگان Let's Encrypt SSL.

## 🚀 نصب و استقرار سریع در لینوکس (One-Line Linux Deployment)

روی سرور لینوکس خود با دسترسی `root` یا `sudo`، دستور زیر را اجرا کنید:

```bash
# کلون مخزن و اجرای اسکریپت نصب:
git clone https://github.com/YOUR_USERNAME/XMessenger.git
cd XMessenger
sudo bash deploy/install.sh
```

اسکریپت به صورت خودکار:
1. پکیج‌های مورد نیاز، داکر و داکر-کامپوز را نصب می‌کند.
2. دامنه شما (مثلاً `chat.example.com`) و ایمیل شما را می‌گیرد.
3. کلیدهای رمزنگاری قوی ۲۵۶ بیتی و رمز عبور تصادفی ادمین را تولید می‌کند.
4. گواهینامه معتبر SSL از Let's Encrypt دریافت کرده و تمدید خودکار آن را فعال می‌سازد.
5. وب‌سرور Nginx را به عنوان Reverse Proxy با پشتیبانی از WebSocket تنظیم می‌کند.
6. کانتینرهای سرویس را بالا آورده و اطلاعات ورود ادمین را در ترمینال نمایش می‌دهد.

## 💻 اجرای محلی جهت توسعه (Local Development)

### پیش‌نیازها
- Node.js نسخه 20 به بالا
- npm

### گام‌ها
1. نصب وابستگی‌ها:
   ```bash
   # نصب وابستگی‌های سرور و کلاینت
   npm --prefix server install
   npm --prefix client install
   ```

2. اجرای همزمان بک‌اند و فرانت‌اند در حالت توسعه:
   ```bash
   # اجرای سرور (پورت 3001)
   npm --prefix server run dev

   # در ترمینال دیگر: اجرای فرانت‌اند (پورت 5173)
   npm --prefix client run dev
   ```

3. باز کردن مرورگر در آدرس:
   ```
   http://localhost:5173
   ```
   - **نام کاربری ادمین پیش‌فرض:** `admin`
   - **رمز عبور ادمین پیش‌فرض:** `Admin@123456`

```
XMessenger/
├── .agents/                   # مستندات و قوانین کدنویسی هوش مصنوعی
├── graphify-out/              # گراف تحلیل کدبیس و بهینه‌سازی توکن
├── server/                    # بک‌اند (Node.js + Express + TypeScript + Socket.io + SQLite)
│   ├── src/
│   │   ├── config/            # تنظیمات و متغیرها
│   │   ├── database/          # مدل‌ها و لایه SQLite
│   │   ├── middleware/        # احراز هویت و مجوزها
│   │   ├── routes/            # مسیرهای Auth, Messages, Admin
│   │   ├── socket/            # سرور رویدادهای زنده سوکت
│   │   ├── utils/             # رمزنگاری AES-256-GCM و هش
│   │   └── workers/           # پاک‌کننده خودکار پیام‌های منقضی (TTL)
├── client/                    # فرانت‌اند (React 19 + Vite + Tailwind CSS + RTL/LTR)
│   ├── src/
│   │   ├── components/        # اجزای رابط کاربری ادمین و کاربر
│   │   ├── i18n/              # بسته‌های زبان فارسی و انگلیسی
│   │   ├── services/          # کلاینت‌های API و WebSocket
│   │   └── stores/            # مدیریت وضعیت (Zustand)
├── deploy/                    # ابزارهای استقرار لینوکسی
│   ├── Dockerfile
│   ├── docker-compose.yml
│   ├── install.sh             # اسکریپت نصب یک‌خطی خودکار
│   └── nginx/                 # کانفیگ پروکسی معکوس و گواهی SSL
└── README.md
```

## 🔒 استانداردهای امنیتی
- پیام‌های ارسالی با **AES-256-GCM** ذخیره می‌شوند.
- ارتباطات کلاینت و سرور روی پروتکل رمزنگاری شده TLS 1.3 / WSS منتقل می‌گردد.
- هیچ متنی از پیام‌های منقضی در فایل‌های لاگ نگهداری نمی‌شود.
