# 🛡️ XMessenger (ایکس مسنجر)

> **پیام‌رسان متمرکز و یک‌طرفه (Hub-and-Spoke Secure Web Messenger)**
> طراحی شده برای امنیت حداکثری، دوزبانه (فارسی راست‌چین و انگلیسی)، پیام‌های گذرا (حذف خودکار پس از انقضا)، حذف آنی دوطرفه، رابط کاربری لوکس و مینیمال و **اسکریپت استقرار خودکار یک‌خطی لینوکس با گواهی رایگان Let's Encrypt SSL**.

---

## ⚡ دستور نصب سریع تک خطی لینوکس (1-Line Quick Installer)

کافی است پورت‌های **80** و **443** سرور باز باشند و دامنه خود (یک A Record) را به IP سرور متصل کرده باشید. سپس دستور زیر را در ترمینال سرور لینوکس (Ubuntu / Debian / CentOS) اجرا کنید:

```bash
curl -sSL https://raw.githubusercontent.com/PouryaDe/XMessenger/main/deploy/install.sh | sudo bash
```

> [!TIP]
> **اجرای مستقیم بدون پرسش تعاملی (Non-Interactive):**
> می‌توانید مشخصات دامنه، ایمیل و رمز ادمین را به عنوان متغیر پیش از دستور ارسال کنید:
> ```bash
> DOMAIN="chat.yourdomain.com" EMAIL="admin@yourdomain.com" ADMIN_PASSWORD="MyStrongPassword123" curl -sSL https://raw.githubusercontent.com/PouryaDe/XMessenger/main/deploy/install.sh | sudo -E bash
> ```

## 📋 مراحل و کارکرد خودکار اسکریپت نصب (`deploy/install.sh`)

اسکریپت نصب به صورت کاملاً خودکار و گام‌به‌گام مراحل زیر را انجام می‌دهد:

1. **بررسی پیش‌نیازها و پکیج‌های پایه:**
   - بررسی دسترسی دسترسی `root/sudo`.
   - نصب خودکار پکیج‌های `curl`، `openssl` و `git` در صورت عدم وجود.
2. **بررسی و نصب داکر (Docker Engine & Compose):**
   - در صورت عدم نصب داکر، موتور رسمی داکر و پلاگین Docker Compose به صورت خودکار نصب و سرویس آن فعال می‌شود.
3. **دریافت اطلاعات دامنه و ایمیل:**
   - نام دامنه (مثلاً `chat.example.com`) و ایمیل جهت ثبت در Let's Encrypt اخذ می‌شود.
   - در صورت تعیین نشدن رمز عبور ادمین، یک رمز عبور تصادفی امن ۱۶ کاراکتری تولید و نمایش داده می‌شود.
4. **تولید کلیدهای رمزنگاری نظامی (Cryptographic Keys):**
   - تولید کلید متقارن ۲۵۶ بیتی امن با `openssl rand -hex 32` برای رمزنگاری فیلدهای دیتابیس (AES-256-GCM).
   - تولید کلید تصادفی JWT Secret برای نشست‌ها و وب‌سوکت‌ها.
5. **اخذ خودکار گواهینامه معتبر SSL از Let's Encrypt:**
   - راه‌اندازی موقت وب‌سرور برای پاسخ به ACME Challenge سرور Let's Encrypt.
   - صدور گواهینامه معتبر TLS/SSL توسط `certbot`.
   - راه‌اندازی تسک خودکار تمدید دوره‌ای گواهی SSL هر ۱۲ ساعت یک‌بار.
6. **پیکربندی Nginx Reverse Proxy:**
   - تنظیم وب‌سرور Nginx برای فوروارد ترافیک به کانتینر برنامه.
   - پشتیبانی کامل از پروتکل‌های **WebSocket (WSS)** جهت چت بلادرنگ.
   - اعمال هدرهای امنیتی سخت‌گیرانه (HSTS, X-Frame-Options, X-Content-Type-Options).
7. **اجرا و بیلد کانتینرهای سرویس:**
   - ایجاد فایل محیطی `.env` و راه‌اندازی کانتینرها در حالت Daemon با دستور `docker compose up -d --build`.
   - تنظیم ری‌استارت خودکار کانتینرها در صورت ریبوت یا کرش سرور (`restart: always`).
8. **نمایش خروجی نهایی:**
   - آدرس دسترسی به پنل وب (`https://yourdomain.com`)، نام کاربری (`admin`) و کلمه عبور در انتهای اسکریپت چاپ می‌شود.

## 🛠️ روش دوم: نصب دستی از طریق کلون مخزن (Manual Clone)

اگر مایلید ابتدا سورس‌کد را بررسی کنید و سپس نصب را انجام دهید:

```bash
# ۱. کلون پروژه
git clone https://github.com/PouryaDe/XMessenger.git /opt/xmessenger
cd /opt/xmessenger

# ۲. اجرای اسکریپت نصب
sudo bash deploy/install.sh
```

---

## 🗂️ مدیریت سرویس پس از نصب

تمامی فایل‌های اجرایی در مسیر `/opt/xmessenger/deploy` (یا پوشه `deploy` در سورس‌کد شما) قرار دارند:

```bash
cd /opt/xmessenger/deploy

# مشاهده لاگ‌های زنده سرور:
docker compose logs -f

# مشاهده وضعیت کانتینرها:
docker compose ps

# ری‌استارت سرویس:
docker compose restart

# متوقف کردن سرویس:
docker compose down

# به‌روزرسانی به آخرین نسخه:
cd /opt/xmessenger
git pull origin main
cd deploy
docker compose up -d --build
```

## 🌟 ویژگی‌های کلیدی پیام‌رسان

- **مدل ارتباطی یک‌طرفه (Hub-and-Spoke):**
  - ارتباط انحصاری کاربر با ادمین؛ کاربران به هیچ وجه امکان مشاهده، جستجو یا ارسال پیام به سایر کاربران را ندارند.
  - ادمین به صورت متمرکز تمام گفتگوها را مشاهده، مدیریت و پاسخ می‌دهد.
- **طراحی UI/UX مدرن، کپسولی و لوکس (Mobile-First & Desktop):**
  - طراحی الهام‌گرفته از مدرن‌ترین اپلیکیشن‌های روز با پس‌زمینه گرم طبیعی، کارت‌های گرد (`rounded-3xl`)، ورودی‌های کپسولی معلق (Floating Pill Input) و دکمه‌های دایره‌ای.
  - پشتیبانی کامل از زبان‌های فارسی (RTL با فونت بهینه‌شده **وزیرمتن**) و انگلیسی (LTR).
  - پشتیبانی از تم تاریک و روشن (Dark / Light mode).
- **پیام‌های گذرا و امنیت حداکثری (Ephemeral & Auto-Destruct):**
  - حذف خودکار پیام‌ها به صورت دوطرفه پس از انقضا (پیش‌فرض ۲۴ ساعت، قابل تغییر در تنظیمات ادمین از ۱۵ دقیقه تا چند روز).
  - حذف قطعی آنی (Delete for Everyone) در هر لحظه توسط کاربر یا ادمین.
  - پاکسازی سخت‌افزاری (Hard-delete) از دیتابیس توسط جاب پس‌زمینه TTL.
- **امنیت و رمزنگاری داده‌ها:**
  - متن پیام‌ها در سطح دیتابیس با استاندارد متقارن **AES-256-GCM** ذخیره می‌شود و هیچ متنی به صورت خام در دیسک ذخیره نمی‌گردد.
  - هش امن رمزهای عبور با الگوریتم مقاوم **bcrypt** با Salt بالا.
  - توکن‌های امنیتی JWT و ارتباطات بلادرنگ بر بستر Secure WebSocket (WSS).
- **کنترل ثبت‌نام در پنل ادمین:**
  - سوییچ فعال‌سازی/مسدودسازی ثبت‌نام عمومی.
  - حالت تایید دستی (Manual Admin Approval): کاربران جدید در وضعیت «در انتظار تایید» قرار می‌گیرند تا پس از تایید توسط ادمین دسترسی چت فعال شود.

## 💻 اجرای محلی جهت توسعه (Local Development)

### پیش‌نیازها
- Node.js نسخه 20 به بالا
- npm

### گام‌ها
1. نصب وابستگی‌ها:
   ```bash
   npm --prefix server install
   npm --prefix client install
   ```

2. اجرای همزمان بک‌اند و فرانت‌اند در حالت توسعه:
   ```bash
   # اجرای سرور (پورت 3001)
   npm --prefix server run dev

   # در ترمینال دیگر: اجرای فرانت‌اند (پورت 5173)
   npm --prefix client run dev
   ```

3. باز کردن مرورگر در آدرس:
   ```
   http://localhost:5173
   ```
   - **نام کاربری ادمین پیش‌فرض:** `admin`
   - **رمز عبور ادمین پیش‌فرض:** `Admin@123456`

```
XMessenger/
├── .agents/                   # مستندات و قوانین کدنویسی هوش مصنوعی و طراحی UI/UX
├── graphify-out/              # گراف تحلیل کدبیس و بهینه‌سازی توکن
├── server/                    # بک‌اند (Node.js + Express + TypeScript + Socket.io + SQLite)
│   ├── src/
│   │   ├── config/            # تنظیمات و متغیرها
│   │   ├── database/          # مدل‌ها و لایه SQLite
│   │   ├── middleware/        # احراز هویت و مجوزها
│   │   ├── routes/            # مسیرهای Auth, Messages, Admin
│   │   ├── socket/            # سرور رویدادهای زنده سوکت
│   │   ├── utils/             # رمزنگاری AES-256-GCM و هش
│   │   └── workers/           # پاک‌کننده خودکار پیام‌های منقضی (TTL)
├── client/                    # فرانت‌اند (React 19 + Vite + Tailwind CSS + RTL/LTR)
│   ├── src/
│   │   ├── components/        # اجزای رابط کاربری ادمین و کاربر
│   │   ├── i18n/              # بسته‌های زبان فارسی و انگلیسی
│   │   ├── services/          # کلاینت‌های API و WebSocket
│   │   └── stores/            # مدیریت وضعیت (Zustand)
├── deploy/                    # ابزارهای استقرار لینوکسی
│   ├── Dockerfile
│   ├── docker-compose.yml
│   ├── install.sh             # اسکریپت نصب یک‌خطی خودکار همراه با SSL
│   └── nginx/                 # کانفیگ پروکسی معکوس و گواهی SSL
└── README.md
```
